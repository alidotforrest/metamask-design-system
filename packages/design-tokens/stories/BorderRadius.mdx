# Border radius

Corner radius tokens name their own value, so `rounded-8` is 8px. The two
bookends are named instead: `rounded-off` removes rounding, and `rounded-full`
rounds a shape fully.

Both Tailwind presets add these tokens alongside Tailwind's default
`borderRadius` scale, so `rounded-lg` and the other stock names still work while
projects migrate. Prefer the tokens in new code — the defaults are intended to
be removed once consumers have moved across.

## Migrating from the default Tailwind names

Each default name maps to exactly one token at the same value, so moving across
is a rename with no visual change.

| Before           | After          |
| ---------------- | -------------- |
| `rounded-none`   | `rounded-off`  |
| `rounded-sm`     | `rounded-2`    |
| `rounded`        | `rounded-4`    |
| `rounded-md`     | `rounded-6`    |
| `rounded-lg`     | `rounded-8`    |
| `rounded-[10px]` | `rounded-10`   |
| `rounded-xl`     | `rounded-12`   |
| `rounded-2xl`    | `rounded-16`   |
| `rounded-3xl`    | `rounded-24`   |
| `rounded-full`   | `rounded-full` |

Corner-specific variants follow the same rename: `rounded-t-3xl` becomes
`rounded-t-24`.

Radii that do not land on the scale need a decision rather than a rename. Round
to the nearest token, or use `rounded-full` when the intent was a circle or a
capsule.

## Circles and capsules

Use `rounded-full`. A radius larger than half the shortest side rounds the shape
fully, so a single token covers every avatar, badge and chip regardless of size.

This is also why the scale stops at 24: anything larger has always been a circle
or a capsule rather than a distinct corner treatment. Only compute a radius
(`size / 2`) when the diameter is dynamic and lives in the same expression.

## Usage outside Tailwind

React Native `StyleSheet` styles and other non-Tailwind styles should import the
values rather than hardcode them.

```tsx
import { borderRadius } from '@metamask/design-tokens';

StyleSheet.create({
  card: { borderRadius: borderRadius[8] },
  avatar: { borderRadius: borderRadius.full },
});
```
